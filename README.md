# 🌍 Island Explorer

An interactive browser game built using HTML, CSS, and JavaScript.

## 🎮 Play

https://island-hopper-1-4.vercel.app

## Features

- 🗺️ Interactive island map
- ⏱️ Built-in timer
- 📍 Location guessing gameplay
- ✅ Instant answer checking
- 📱 Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Running Locally

1. Clone the repository

```bash
git clone https://github.com/yourusername/island-explorer.git
```

2. Open `index.html` in your browser.

No installation required.
